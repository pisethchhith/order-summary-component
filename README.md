### What I learned

After building this project, I learned I can resize width by combining with max-width for set how much size that it suitable and it also make it more responsive too.

Here's what I learned in this snippet code:
```css
/* main section : desktop */
.order{
    ...
    width: 100%;
    max-width: 450px;
}

/* mobile-responsive */
@media screen and (max-width: 768px){
    .order {
        width: 100%;
        max-width: 345px;
    }
}
```
